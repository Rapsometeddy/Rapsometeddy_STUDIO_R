# 💜 Rapsometeddy STUDIO R

A mobile-first music creation workspace for the Rapsometeddy ecosystem.

## Direction

**CREATE → BEAT → VOCALS → SONG → EXPORT**

The studio is designed around original, rights-safe music creation rather than copying commercial recordings.

### Core goals

- 🎹 Original browser-based instruments and patterns
- 🥁 Drum / beat sequencing
- 🎚️ BPM, key and transport controls
- 🎤 Vocal/song workspace
- 📝 Lyrics and song-section planning
- 🔊 Browser audio preview
- 💾 WAV export where supported
- 💜 Rapsometeddy crowned-R visual identity
- 📱 Galaxy-friendly mobile-first interface

## Rights-first audio

The studio should clearly distinguish:
- **Original/generated material** — created by the studio.
- **Third-party material** — only used when its license permits the intended use.
- **Commercial copyrighted recordings** — never presented as royalty-free.

No instrument should be labelled “royalty-free” unless its actual source/license supports that claim.
